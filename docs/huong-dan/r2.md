# Hướng dẫn: kho media Cloudflare R2

Mục tiêu: một kho lưu ảnh và âm thanh miễn phí (10GB), CMS tải file thẳng lên kho, game đọc file qua địa chỉ công khai.

## 1. Tạo tài khoản và bật R2

1. Vào https://dash.cloudflare.com/sign-up, tạo tài khoản (email + mật khẩu), xác nhận email.
2. Ở menu trái, chọn **R2 Object Storage**.
3. Bấm **Purchase R2 Plan** / **Get started** để bật R2. Cloudflare yêu cầu thêm phương thức thanh toán, nhưng gói miễn phí (10GB lưu trữ, không tính phí băng thông tải ra) không bị trừ tiền nếu dùng trong hạn mức.

## 2. Tạo bucket

1. **R2 Object Storage** → **Create bucket**.
2. **Bucket name**: `opes-gamehub-media`.
3. **Location**: chọn **Provide a location hint** → **Asia-Pacific (APAC)**.
4. Bấm **Create bucket**.

## 3. Bật địa chỉ công khai

1. Mở bucket `opes-gamehub-media` → tab **Settings**.
2. Mục **Public Development URL** (hoặc **R2.dev subdomain**) → **Enable** → gõ `allow` để xác nhận.
3. Ghi lại địa chỉ dạng `https://pub-xxxxxxxx.r2.dev`. Đây là giá trị **`MEDIA_PUBLIC_URL`**.

> Địa chỉ `r2.dev` có giới hạn tốc độ, Cloudflare khuyến cáo không dùng cho chạy thật. Đủ cho link chơi thử giai đoạn 1. Khi chạy chiến dịch thật, gắn tên miền riêng ở mục **Custom Domains**.

## 4. Cho phép CMS tải file lên (CORS)

1. Vẫn trong tab **Settings**, mục **CORS Policy** → **Add CORS policy** (hoặc **Edit**).
2. Dán nội dung sau rồi **Save**:

```json
[
  {
    "AllowedOrigins": ["https://opes-gamehub-cms.vercel.app"],
    "AllowedMethods": ["PUT", "GET", "HEAD"],
    "AllowedHeaders": ["Content-Type"],
    "MaxAgeSeconds": 3600
  }
]
```

Nếu tên miền CMS của bạn khác, sửa lại cho đúng. Khi chạy CMS trên máy để phát triển, thêm `"http://localhost:3000"` vào `AllowedOrigins`.

## 5. Tạo khóa truy cập (chỉ cho bucket này)

1. Trang **R2 Object Storage** (tổng quan) → **Manage API tokens** (hoặc **API** → **Manage API Tokens**).
2. **Create API token** (loại *Account API token* hoặc *User API token* đều được):
   - **Token name**: `opes-gamehub-api`
   - **Permissions**: **Object Read & Write**
   - **Specify bucket(s)**: **Apply to specific buckets only** → chọn `opes-gamehub-media`
   - **TTL**: **Forever**
3. Bấm **Create API Token**. Màn kết quả hiện 3 giá trị **chỉ một lần**:
   - **Access Key ID** → `S3_ACCESS_KEY_ID`
   - **Secret Access Key** → `S3_SECRET_ACCESS_KEY`
   - **S3 endpoint** dạng `https://<account-id>.r2.cloudflarestorage.com` → `S3_ENDPOINT` (bỏ phần `/opes-gamehub-media` ở cuối nếu có)

Đây là thông tin bí mật: không dán vào chat, tài liệu hay code.

## 6. Đặt biến môi trường cho API trên Vercel

Dự án **`opes-gamehub-api`** → **Settings** → **Environment Variables**, thêm từng biến (giữ chọn cả Production, Preview, Development):

| Key | Value |
|---|---|
| `S3_ENDPOINT` | `https://<account-id>.r2.cloudflarestorage.com` |
| `S3_REGION` | `auto` |
| `S3_BUCKET` | `opes-gamehub-media` |
| `S3_ACCESS_KEY_ID` | Access Key ID ở bước 5 |
| `S3_SECRET_ACCESS_KEY` | Secret Access Key ở bước 5 |
| `MEDIA_PUBLIC_URL` | `https://pub-xxxxxxxx.r2.dev` ở bước 3 |
| `SESSION_SECRET` | Chuỗi ngẫu nhiên tối thiểu 32 ký tự (xem dưới) |

**Tạo `SESSION_SECRET`:** mở https://www.random.org/strings/?num=1&len=40&digits=on&upperalpha=on&loweralpha=on&unique=on&format=html&rnd=new (hoặc dùng trình quản lý mật khẩu tạo chuỗi 40 ký tự). Đây là khóa ký phiên đăng nhập; đổi khóa này sẽ đăng xuất mọi người.

Sau đó **Deployments** → bản mới nhất → **⋯** → **Redeploy**.

## 7. Kiểm tra

1. Mở CMS → đăng nhập → **Media** → **Tải file lên** một ảnh.
2. Ảnh hiện trong danh sách là thành công.
3. Nếu báo "Không tải được … lên kho media": kiểm tra lại CORS ở bước 4 (đúng tên miền CMS, có `PUT` và `Content-Type`).
