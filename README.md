# Game Hub OPES

Nền tảng tạo và vận hành minigame marketing cho nhãn hàng.

- **CMS**: nhân viên OPES quản lý template, kho quà, hồ sơ nhãn hàng và chiến dịch.
- **Trang người chơi**: mỗi chiến dịch xuất bản thành một link web, khách chơi không cần đăng nhập.
- **API**: nơi duy nhất đọc/ghi dữ liệu, giữ luật chơi, phát quà và chống gian lận.

Tài liệu thiết kế nằm trong thư mục [`docs/`](docs/).
